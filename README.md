# StrongFit Studio

Un pagina visual de alta fidelidad del sitio web oficial de StrongFit Studio, construido para demostrar técnicas modernas de desarrollo web, diseño responsive y UI/UX inmersiva.

## Project Overview

Este proyecto es una recreación del sitio web promocional de StrongFit Studio. Se enfoca en capturar la estética moderna y energética del gimnasio a través de atención meticulosa al detalle, animaciones fluidas y elementos interactivos.

## Features

- **Immersive Hero Section**: Introducción visual a pantalla completa con estilo energético y motivador.
- **Interactive Carousels**:
  - **Showcase de Entrenadores**: Navega a través de nuestro equipo de entrenadores certificados.
  - **Galería de Instalaciones**: Carrusel mostrando nuestras instalaciones y equipos de última generación.
- **Rich Content Sections**:
  - **Services & Location**: Secciones detalladas sobre nuestros servicios y programas de entrenamiento.
  - **Membresías & Precios**: Información completa sobre planes de membresía y opciones de pago.
- **Dynamic Animations**:
  - Efectos de aparición al hacer scroll.
  - Transiciones suaves y efectos hover.
  - Animaciones de contadores para estadísticas y resultados.
- **Responsive Design**: Completamente optimizado para dispositivos desktop, tablet y móviles.

## Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **Linting**: ESLint

## Getting Started

Para ejecutar este proyecto localmente, sigue estos pasos:

1.  **Clona el repositorio** o descarga el código fuente.



2.  **Instala las dependencias**:
    ```bash
    npm install
    ```

3.  **Inicia el servidor de desarrollo**:
    ```bash
    npm run dev
    ```

4.  **Abre en tu navegador**:
    La terminal mostrará la URL local (normalmente `http://localhost:5173`).

## Estructura del Proyecto

El código fuente del proyecto está organizado en `src/`:

- **`components/`**: Componentes UI reutilizables (Hero, Navbar, Footer, Secciones, Carruseles).
- **`assets/`**: Imágenes, iconos y otros recursos estáticos.
- **`App.jsx`**: Componente principal de la aplicación que ensambla las secciones.
- **`index.css`**: Estilos globales y directivas de Tailwind.

## ⚠️ Note
Este es un proyecto de portafolio y no está afiliado oficialmente con StrongFit Studio. Todas las imágenes y contenido son utilizados con fines demostrativos.
